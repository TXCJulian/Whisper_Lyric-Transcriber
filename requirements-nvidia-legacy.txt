# Legacy NVIDIA GPU support (Maxwell/Pascal/Volta, e.g. Quadro M4000).
#
# PyTorch's own CUDA support matrix keeps the cu126 wheel line as the
# designated "legacy" build specifically to retain Maxwell/Pascal/Volta
# kernels (sm_50+) that CUDA 13.x (and torch's cu128/cu130 wheels) dropped
# -- see https://github.com/pytorch/pytorch/issues/178665. Pin the same
# torch version as requirements-nvidia.txt, just on that legacy CUDA line,
# so this file doesn't drift from the rest of the project on version bumps.
# torchaudio stopped publishing releases past 2.11.0 on cu126 (same reason
# requirements-nvidia.txt itself pairs a newer torch with torchaudio 2.11.0).
#
# CTranslate2 (faster-whisper's backend) separately dropped Maxwell/sm_5x
# kernels from its prebuilt wheels in its own CUDA 12 migration (v4.0), so
# this backend uses openai-whisper (plain PyTorch, no CTranslate2) instead
# of faster-whisper -- see app/gpu_backend.py's use_faster_whisper().
--index-url https://download.pytorch.org/whl/cu126
--extra-index-url https://pypi.org/simple
torch==2.13.0
torchaudio==2.11.0
openai-whisper==20250625
-r requirements.txt
